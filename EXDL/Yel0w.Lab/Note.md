## Running the Experiment (Backend)

The experiment binaries can be downloaded from the following repository:

**N-Body (Demonstration):**  
https://github.com/Yel0w08/storage.archive.data/blob/main/Yel0w.Lab/Exp/Bin/win/N-Body.zip

or using the raw link : https://github.com/Yel0w08/storage.archive.data/raw/refs/heads/main/Yel0w.Lab/Exp/Bin/win/N-Body.zip

### To run

1. Download the **`N-Body.zip`** archive from the link above.

2. Extract the contents of the archive.

3. Open the extracted folder.

4. Run **`run.bat`** to start the experiment.

> **Note:** On Windows, you may need to confirm the security prompt (SmartScreen) before the application launches if the executable is not digitally signed.
